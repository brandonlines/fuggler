# Steal a Fuggler

A lightweight 8-bit HTML/Canvas game built around a classic steal-and-escape loop, fully themed around Fugglers.

## Play Loop
- Move around the map.
- Steal Fugglers.
- Return each one to the hideout.
- Dodge guards and beat the timer.
- Clear all Fugglers to advance levels.

## Controls
- Move: `WASD` or Arrow Keys
- Mobile/Mouse: tap/click destination on the map or use virtual buttons
- Sprint: `Shift`
- Start/Restart: `Space`

## Run Locally
Open `index.html` in a browser.

## Host on GitHub Pages
1. Push these files to your repo at [brandonlines/fuggler](https://github.com/brandonlines/fuggler).
2. In GitHub, open **Settings > Pages**.
3. Set **Source** to `Deploy from a branch`.
4. Choose branch `main` (or your default branch) and folder `/ (root)`.
5. Save and wait for Pages to publish.

Your game will be live at:
`https://brandonlines.github.io/fuggler/`
